Data Types

Every object you create in R has a data type. The data type determines what kind of values an object can hold, and what operations make sense on it: you can add two numbers together, but adding two pieces of text doesn’t mean anything the same way. Knowing an object’s data type helps you understand what R will let you do with it, and helps you spot bugs when something doesn’t behave the way you expect.

Vectors

Vectors are data types with one-dimension where all elements in the vector are of the same type. R has several basic vector types:

  • character: text, e.g. "hello"
  • numeric: decimal numbers, e.g. 3.14
  • integer: whole numbers, e.g. 5L
  • logical: TRUE / FALSE
  • factor: categorical data with fixed levels, e.g. "low", "medium", "high"
char_vec = c("apple", "banana", "cherry")
num_vec = c(1.5, 2.7, 3.9)
int_vec = c(1L, 2L, 3L)
log_vec = c(TRUE, FALSE, TRUE)
fac_vec = factor(c("low", "high", "medium"), levels = c("low", "medium", "high"))

L suffix: Writing 5L tells R to store the value as an integer rather than a numeric (double). Without the L, a whole number like 5 is stored as numeric by default. In practice the distinction rarely matters for day-to-day analysis, but you’ll see L used when a function specifically expects an integer (e.g. nrow, or arguments like nrow = 2L in some packages).

NA: R’s representation of a missing value. It can appear inside any vector type (e.g. c(1, 2, NA, 4)) and will show up often once you start working with real data.

Checking Data Types

class(char_vec)
str(fac_vec)
length(num_vec)

class(): Tells you what type an object is. str(): Gives you a compact summary of an object’s structure. length(): Tells you how many elements are in it.

Accessing Elements

char_vec[1]        # by position
names(num_vec) = c("a", "b", "c")
num_vec["b"]        # by name

R indexing starts at 1, not 0. char_vec[1] gives you the first element, not the second.

Matrix

A matrix is a 2-dimensional structure where every element must be the same type (usually numeric).

m = matrix(1:6, nrow = 2, ncol = 3)
m
dim(m)
m[1, 2]     # row 1, column 2

Matrix: A rectangular grid of values, all of the same data type, arranged in rows and columns.

Naming Rows and Columns

You can give a matrix row names and column names when you create it, using the dimnames argument, or by setting rownames() and colnames() afterward:

m2 = matrix(1:6, nrow = 2, ncol = 3,
            dimnames = list(c("row1", "row2"), c("col1", "col2", "col3")))
m2

# equivalently
m3 = matrix(1:6, nrow = 2, ncol = 3)
rownames(m3) = c("row1", "row2")
colnames(m3) = c("col1", "col2", "col3")
m3

Once named, you can index by name instead of position:

m2["row1", "col2"]   # single element, by row name and column name
m2["row2", ]           # entire row, by row name
m2[, "col3"]           # entire column, by column name

Naming rows and columns makes your code more readable and less fragile: m2["row2", ] is much clearer than m2[2, ], and it keeps working even if you later reorder the rows.

List

A list can hold elements of different types and lengths, even other lists.

my_list = list(name = "Alice", age = 25, scores = c(90, 85, 88))
my_list$name
my_list[["scores"]]

List: A flexible container that can hold objects of different types and sizes together, accessed using $ (by name) or [[ ]] (by name or position).

You won’t use matrix and list constantly in this course, but you’ll see them show up under the hood (a data frame is technically a special kind of list!). It’s worth recognizing them when you see them.

Data Frame

A data frame is the structure you’ll use the most, think of it as a spreadsheet: rows are observations, columns are variables, and different columns can hold different types.

df = data.frame(
  name = c("Alice", "Bob", "Carol"),
  age = c(25, 30, 22),
  passed = c(TRUE, FALSE, TRUE)
)
df
df$age          # access a column by name
df[1, ]         # access a row by position

Data frame: A table-like structure where each column can be a different data type, but all columns must have the same number of rows. In fact, a data frame is a special kind of list: each column is an element of the list, and the requirement that makes it a data frame (rather than a plain list) is that every element must have the same length.

Exercise 1.2

  1. Create one of each fundamental data type (character, numeric, integer, logical, factor). Check each with class(), str(), and length().
  2. Create a small matrix with matrix() and access one element using [row, col].
  3. Create the same matrix but with row names and column names, and access the same element using its row name and column name instead.
  4. Create a small list with at least two different types of elements and access one using $ or [[ ]].
  5. Create a data frame with at least 2 columns and 3 rows. Access a single column and a single row.
